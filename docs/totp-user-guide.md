# TOTP (Two‑Factor Authentication) – End‑User Guide
---
## 1. Overview
The **TOTP** feature adds an extra layer of security to user authentication by requiring a time‑based one‑time password (6‑digit code) generated by an authenticator app (Google Authenticator, Authy, etc.) after the primary password login.

## 2. Permissions
| Action | Required permission |
|--------|----------------------|
| Enable/disable TOTP for own account | `view-own-profile` / `update-own-profile` |
| Enforce TOTP for all users (admin) | `manage-users` |
| Bypass TOTP for service accounts | `manage-api-keys` |

If you lack permission the UI will not show the TOTP setup options.

## 3. Related Settings
- **authConfig.totpEnabled** – Global toggle to require TOTP for all users.
- **authConfig.totpIssuer** – Name displayed in authenticator apps.

These settings are edited in **Settings → Authentication**.

## 4. UI Pages & Workflow
- **TOTP Setup** (`/settings/security`): Users can scan a QR code with their authenticator app, then enter the generated code to verify.
- **Login Flow**: After entering username/password, if TOTP is enabled, a second screen prompts for the 6‑digit code.
- **Recovery**: Users can generate backup codes (one‑time use) in the security settings page.

## 5. API Reference
| Method | Path | Description | Permission |
|--------|------|-------------|------------|
| POST | `/auth/totp/setup` | Initiate TOTP setup, returns QR data | `update-own-profile` |
| POST | `/auth/totp/verify` | Verify the TOTP code entered by the user | `update-own-profile` |
| POST | `/auth/totp/disable` | Disable TOTP for the account | `update-own-profile` |
| GET | `/auth/totp/recovery-codes` | Retrieve (or generate) backup codes | `update-own-profile` |

## 6. Edge Cases & Gotchas
- **Clock drift** – Ensure the device time is accurate; otherwise generated codes may be rejected.
- **Lost device** – Use backup codes or contact admin to reset TOTP.
- **Admin enforcement** – When `authConfig.totpEnabled` is true, all users except those with `manage-api-keys` must configure TOTP.

## 7. Quick Actions Summary
- **Set Up TOTP** → Settings → Security → **Enable** → scan QR → enter code → **Verify**.
- **Disable TOTP** → Settings → Security → **Disable** → confirm.
- **Generate Backup Codes** → Settings → Security → **Generate Codes** → copy/store safely.
